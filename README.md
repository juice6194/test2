# 开放资料库

欢迎提交和分享有用的资料、学习笔记、教程及资源链接。

[浏览资料](https://github.com/juice6194/test2/tree/main/materials) · [提交资料推荐](https://github.com/juice6194/test2/issues/new?template=material.yml) · [Fork 后上传文件](https://github.com/juice6194/test2/fork)

## 如何提交资料

需要登录 GitHub 账号，可选择以下方式：

1. **上传文件**：Fork 本仓库，在自己的副本中进入 `materials/`，点击 **Add file → Upload files** 上传资料并提交更改，然后点击 **Contribute → Open pull request**，提交给维护者审核。
2. **推荐链接或提出建议**：进入本仓库的 **Issues → New issue → 提交资料**，填写标题、资料说明和来源链接。

Pull Request（PR）通过维护者审核并合并后，资料将出现在本仓库中。公开仓库允许其他人提出贡献，直接修改仓库需要维护者授予写入权限。

## 资料目录

- [materials/](materials/)：按主题分类的资料与链接说明。
- [贡献指南](CONTRIBUTING.md)：文件命名、来源标注及审核要求。

## 分享原则

请仅提交你有权公开分享的内容，标明作者、来源和适用许可。第三方资料保留原作者声明；不方便转载时，请提交原始链接及简介。

本仓库暂未为所有资料统一授予开放许可；公开可见不等于可以任意转载或商用，使用时请核对对应资料的授权说明。
