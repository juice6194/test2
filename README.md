# 如何提交资料

## 上传文件

1. 登录 GitHub，点击右上角 **Fork → Create fork**。
2. 在自己的仓库副本中进入 `materials/` 目录。
3. 点击 **Add file → Upload files**，上传资料。
4. 填写提交说明，点击 **Commit changes**。
5. 回到自己的仓库首页，点击 **Contribute → Open pull request**。
6. 填写标题和说明，点击 **Create pull request**，等待审核合并。

## 提交资料链接

1. 打开 [资料提交表单](https://github.com/juice6194/test2/issues/new?template=material.yml)。
2. 填写资料名称、简介、来源和授权说明。
3. 点击 **Create** 提交。
